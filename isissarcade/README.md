# ISISS Arcade — Logo Blaster Mixed Reality

Versione MR basata sul comportamento WebXR funzionante del prototipo fornito: scena A-Frame, oggetti e raycasting gestiti con Three.js, sessione `immersive-ar` gestita direttamente da WebXR.

## Gameplay
- 60 secondi
- Il logo ISISS Matese è il bersaglio
- Il logo si muove nello spazio reale e reagisce alla vicinanza
- Grilletto del controller = sparo
- 100 punti base, combo fino a x5
- Precisione e combo massima nella schermata finale
- Rilevamento dei piani e dei confini disponibili nel visore

## Pubblicazione
Usare HTTPS, ad esempio GitHub Pages. Aprire `vr/` oppure `games/space-blaster/` nel browser del visore.
